# Sound files (optional)

Put an .mp3 here with one of these names and the app plays it instead of its built-in sound.
A missing file simply falls back to the built-in sound.

| file | when it plays |
|---|---|
| correct.mp3 | right answer |
| wrong.mp3 | wrong answer (keep it gentle) |
| level.mp3 | moved up a level in a topic |
| medal.mp3 | gold medal in a topic |
| trophy.mp3 | trophy in a topic |
| buy.mp3 | bought an animal in the camp shop |
| gift.mp3 | the chest opens at the end of a practice |
| finish.mp3 | end of a good practice (fanfare + applause, about 3 s) |
| done.mp3 | end of a weaker practice (soft, encouraging) |
| tap.mp3 | turning sounds back on |

Short files (under 2 s, except finish up to 3-4 s), mp3, under 100 KB each.
